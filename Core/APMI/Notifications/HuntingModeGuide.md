APMI hunting shortcuts

NumPad 0: Toggle hunting
NumPad +: Reset hunting
Shift+F11: Frame analysis dump
NumPad 7/8/9: Previous / next / mark index buffer
NumPad 4/5/6: Previous / next / mark vertex shader
NumPad 1/2/3: Previous / next / mark pixel shader
NumPad Decimal + 1/2/3: Previous / next / mark compute shader

Ctrl+F12: Close this guide
