APMI development package for Azur Promilia

F10: Reload mod files
F11: Toggle mods
F12: Show or hide this guide
Ctrl+F12: Hunting shortcuts
Shift+F11: Save a frame analysis dump

Use APMI Launcher Settings to choose this package and enable MCP capture.
Put APMI-compatible mods in Mods. Mesh hashes use whole-buffer hashing.

This Core handles AP compute skinning and native multi-pass mesh replacement.
Each component keeps its game's bone palette and original material bindings.
